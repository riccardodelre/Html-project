# Html-project
Progetto di HTML di Del Re Riccardo e Ghilardi Lucas 

Questo sito propone alcune delle ricette più iconiche della tradizione culinaria italiana nell'ambito delle feste pasquali. Dalla home si può comodamente accedere alle sezioni di antipasti, primi, secondi e dolci, ognuna contenente sei ricette deliziose. In seguito è possibile tornare alla pagina principale da ogni sezione per poi scoprire gli altri piatti.
